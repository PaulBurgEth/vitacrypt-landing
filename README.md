## About VitaCrypt

The only consumer app that unifies a person's whole health — genetics, wearables, labs, microbiome, environment and lifestyle — into one profile that returns actionable, evidence-checked guidance. Built private by design.

Privacy is the trust layer that makes centralizing this data acceptable. Blind compute (the server computing on ciphertext) is proven on one encrypted genetic slice on staging today; production-wide blind compute is on the roadmap, and the platform is not yet end-to-end blind (the master key is currently server-side).

### What makes it different

| | Traditional Apps | VitaCrypt |
|---|---|---|
| Scope | One silo (wearable / DNA / labs) | Six streams, unified into one profile |
| Guidance | Generic segments | Whole-profile, evidence-checked (real PubMed PMIDs) |
| Personalization | Generic segments | Read against your genotype and local environment |
| Privacy | At rest only | Private by design (FHE; targeting Zama Concrete ML / TFHE) |
